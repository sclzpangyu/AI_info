# AI_info

AI每日资讯简报与月度报告仓库

## 目录结构

```
├── daily/          # 每日AI资讯简报
│   ├── YYYY-MM-DD.md
│   └── ...
├── monthly/        # 月度AI产业报告
│   ├── YYYY-MM.md
│   └── ...
└── README.md
```

## 说明

- **每日简报**：每天早上8:00自动生成，包含三部分：摘要、AI科技咨询、新材料与技术前沿
- **月度报告**：每月最后一天晚上20:00自动生成，完整版涵盖融资、投资赛道、应用落地、政策、芯片算力、市场需求、机器人、新材料、国内外对比、市场反馈、下月展望等
- 所有报告均标注准确时间点，附带信息来源链接

## 更新方式

每日/每月报告通过PR合并到main分支。
